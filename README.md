# 🧪 STUNK

> **Launch onchain coins paired with stocks, memes, currencies & more.**

STUNK is an onchain token launch and discovery platform built around **asset-paired markets**.

Create, launch, and discover the next generation of onchain coins — paired with **stocks, memes, currencies, commodities, leverage, and custom assets**.

🌐 Website: https://stunk.fun/
𝕏 X: https://x.com/stunkfun

---

## 🚀 What is STUNK?

STUNK brings different asset classes into a single onchain token ecosystem.

Instead of launching tokens in isolation, creators can build coins around a chosen pair and create markets connected to a broader asset narrative.

### Supported Pair Types

* 📈 Stocks
* 😂 Memes
* 💵 Currencies
* 🪙 Crypto Assets
* 🛢️ Commodities
* ⚡ Leverage
* 🧩 Custom Pairs
* 🌐 More asset classes over time

## 🔥 Asset-Paired Launches

STUNK allows creators to choose the narrative and asset class behind their token.

Examples:

```text
$TOKEN × Stock
$TOKEN × Meme
$TOKEN × Currency
$TOKEN × Commodity
$TOKEN × Crypto
$TOKEN × Custom Asset
```

The pairing system creates a different way to discover and trade tokens onchain.
